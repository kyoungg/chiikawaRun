# chiikawaRun# 🐹 치이카와 영상 정주행 웹사이트

> 치이카와 정주행을 위한 팬 메이드 웹사이트입니다

## 📌 프로젝트 소개

치이카와 애니메이션 영상을 보다 편리하게 감상할 수 있도록 제작하는 웹 프로젝트입니다.

영상을 한곳에서 탐색하고, 에피소드를 엔딩 곡 없이 이어서 감상할 수 있는 서비스를 목표로 합니다.

## ✨ 주요 기능

- 🎬 **영상 감상** — 웹사이트에서 치이카와 영상 감상
- ▶️ **정주행 기능** — 영상을 순서대로 이어서 감상
- 📱 **반응형 UI** — PC와 모바일 환경 지원

_위 기능은 개발 목표이며, 실제 구현 여부에 따라 수정할 예정입니다._

## 🛠️ 기술 스택

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS, shadcn/ui
- **Language:** JavaScript
- **Video:** YouTube IFrame Player API

## 🚀 시작하기

### 1. 저장소 클론

```bash
git clone <repository-url>
cd chiikawaRun
```

### 2. 패키지 설치

```bash
npm install
```

### 3. 개발 서버 실행

```bash
npm run dev
```

터미널에 표시되는 로컬 주소로 접속합니다.
